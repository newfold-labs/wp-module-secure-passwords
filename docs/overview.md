# Overview

**wp-module-secure-passwords** prevents use of passwords known to be exposed in data breaches and encourages better password hygiene for WordPress sites. It registers with the Newfold Module Loader. No runtime Composer requires. Maintained by Newfold Labs. Distributed via Newfold Satis.
